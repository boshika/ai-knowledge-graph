Uses ASR to convert speech to text. Automatically removes PII data using redaction. Multi-lingual detection. In a generative AI architecture, it often serves as a pre-processing layer for voice-based applications, converting audio input into text before it is sent to a foundation model like Claude or Titan

Use Cases
- call centers
- closed captioning and transcribing
- generating metadata for media assets for searchable archiving

**Core Capabilities**

- **Multilingual Support:** It features automatic language identification for audio containing multiple languages.
- **Privacy and Safety:** The service can automatically redact personally identifiable information (PII) and includes ML-powered toxicity detection that analyzes speech cues like tone and pitch to identify hate speech or harassment.
- **Accuracy Optimization:** You can improve transcription quality using **Custom Vocabularies** for brand names and acronyms, or **Custom Language Models** to help the model learn domain-specific context
